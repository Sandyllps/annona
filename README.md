# Annona

Aplicativo Android para **gestão da despensa doméstica**. Cadastre o que você tem em casa, acompanhe a validade e evite o desperdício de alimentos, com dicas de armazenamento, receitas e apoio à doação.
<br>

> Projeto da disciplina de Programação para Dispositivos Móveis (Mobile I e Mobile II). **Em desenvolvimento.**

<br>


## Sobre o projeto

Muitos alimentos e produtos passam da validade esquecidos no fundo do armário ou da geladeira. O resultado é dinheiro jogado fora e comida desperdiçada.

O Annona funciona como um inventário inteligente da despensa: a pessoa cadastra o que comprou, o app acompanha os prazos e recebe ajuda para decidir o que fazer com cada item: **consumir logo, cozinhar uma receita ou doar**.

<br>

### Fluxo de trabalho

1. Atualizar a branch `main` local com as alterações do GitHub.
2. Criar uma branch para a tarefa.
3. Desenvolver a alteração nessa branch.
4. Fazer commit das alterações e enviá-las ao GitHub.
5. Criar um Pull Request da branch para a `main`.
6. Solicitar a revisão de outro integrante da equipe.
7. Após a aprovação, realizar o merge na `main`.
8. Excluir a branch após o merge.

```bash
git checkout main
git pull origin main
git checkout -b feature/nome-da-tarefa
# ... desenvolver ...
git add arquivo1 arquivo2
git commit -m "feat: descreve o que foi feito"
git push -u origin feature/nome-da-tarefa
```
